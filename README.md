This lab covered 3 fronts, domain name system, Web Server, and File Transfer control protocol. The web server portion was quick and succinct, because it was very straight forward. The FTP section highlighted some of the ways security configurations, or lack thereof, plays a role on a server setup for transferring files publicly. Lastly the DNS section was a detailed explanation into the nuances of how DNS is setup, utilized, and interacts across devices. Things like pinging servers, how long they cache the data, and how to flush the data was all hands on practiced.

I learned the way forward lookup zones and reverse lookup zones work firsthand. I was familiar with this concept from my previous studies, but executing it myself and pinging everything aided in my understanding of how it works in practice.

I thought it was interesting setting up the dns and the websites knowing that it was entirely local. I’m going to mess around with that more.
